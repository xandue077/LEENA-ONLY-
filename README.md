# LEENA ML

This version is **ready for GitHub Pages**. No Node.js or build step is required.

## Upload
Upload everything inside this folder to the root of your GitHub repository, keeping `assets/` next to `index.html`.

## Files in `assets/`
- `cute-love.gif` — the animated GIF
- `our-song.mp3` — Sweet Boy
- `song-cover.jpg` — the only song picture, shown both in the page and on the left of the song name
- `our-days.jpg` — the picture for Box #2 / Our Days

## Pages inside the experience
1. Love test
2. Three surprise boxes
3. Sweet Boy music page
4. Automatic relationship day counter
5. Love letter for Leena

The day counter uses August 22, 2026 as Day 1, so it increases automatically every calendar day.
